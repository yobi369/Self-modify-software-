# Security policy

## Supported versions

Security fixes are applied to the current default branch. Until versioned releases are established, no older release is guaranteed to receive security updates.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository where available. If it is unavailable, contact the maintainer through a private channel listed on the maintainer's GitHub profile.

Include:
- A concise impact statement.
- Affected commit or deployment.
- Reproduction steps and required privileges.
- Proof-of-concept that does not access real customer data.
- Suggested mitigation, if known.

Do not publish credentials, personal data, customer source code, or exploit details in public issues. The maintainer will acknowledge and triage reports as soon as practical.
